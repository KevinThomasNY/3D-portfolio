# Triage labels

Use the same string for each skill role and ticket status.

- `needs-triage` — Awaiting maintainer review.
- `needs-info` — Awaiting more information from the reporter.
- `ready-for-agent` — Specified and ready for an agent to implement.
- `ready-for-human` — Requires human implementation.
- `wontfix` — Closed without action.

# Local Markdown issue tracker

- Keep each feature in `.scratch/<feature-slug>/`.
- Save the spec as `spec.md` in the feature directory.
- Save one file per ticket under `issues/` as `<NN>-<slug>.md`, starting at `01`. Create directories as needed.
- When fetching a ticket, use its path or look up its number within the feature.
- Record triage near the top of the ticket as `Status: <label>`. Use the values in `triage-labels.md`.
- Append ticket comments under `## Comments`.
